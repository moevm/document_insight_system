# Вики: Юнит-тесты критериев проверки отчетов

Данный документ описывает 34 юнит-теста, реализованных для 9 критериев проверки отчетов в проекте DIS.

## Общая информация
- **Расположение:** `tests/reports/`
- **Фикстуры:** `tests/fixtures/reports/`
- **Утилиты:** `tests/util/report_file_utils.py`
- **Фреймворк:** pytest
- **Параллелизация:** pytest-xdist

## Описание критериев и сценариев

### 1. first_pages_check (Проверка титульных листов)
- **Описание:** Проверяет наличие обязательных начальных страниц (Титульный лист, Задание, Календарный план).
- **Сценарии:**
  - Валидный документ со всеми страницами.
  - Инвалидный документ с отсутствующими обязательными страницами.
  - Проверка корректности обнаружения по маркерам.

### 2. needed_headers_check (Проверка обязательных заголовков)
- **Описание:** Проверяет наличие обязательных структурных заголовков (Введение, Заключение и т.д.).
- **Сценарии:**
  - Полный набор обязательных заголовков.
  - Отсутствие обязательных заголовков.
  - Ошибка проверки при недостаточном количестве страниц в документе.

### 3. max_abstract_size_check (Размер аннотации)
- **Описание:** Контролирует количество слов или страниц в разделе "Реферат" / "Abstract".
- **Сценарии:**
  - Аннотация в рамках лимитов.
  - Превышение лимита слов/страниц.
  - Граничный случай: объем ровно по лимиту.

### 4. literature_references (Ссылки на литературу)
- **Описание:** Сверяет список литературы с основным текстом работы.
- **Сценарии:**
  - Все источники из списка упомянуты в тексте.
  - Неиспользуемые источники в библиографии.
  - Сложные диапазоны ссылок (например, [1-5]).
  - Смешанные ссылки (например, [1, 3-4]).
  - Обнаружение пустого списка литературы.

### 5. image_references (Ссылки на изображения)
- **Описание:** Гарантирует, что на каждое изображение в тексте есть соответствующая ссылка.
- **Сценарии:**
  - Все изображения корректно процитированы.
  - Отсутствие ссылок на некоторые изображения.
  - Ссылки на несуществующие номера рисунков.

### 6. page_counter (Счетчик страниц)
- **Описание:** Сверяет общее количество страниц со стандартами.
- **Сценарии:**
  - Количество страниц в пределах нормы.
  - Количество страниц ниже минимума.
  - Количество страниц выше максимума.
  - Граничные случаи: ровно на минимальном и максимальном лимитах.

### 7. banned_words_check (Запрещенные слова)
- **Описание:** Ищет недопустимую лексику в тексте отчета.
- **Сценарии:**
  - "Чистый" документ без запрещенных слов.
  - Обнаружение слов из черного списка.
  - Обнаружение потенциально опасных слов (warning).
  - Проверка на слишком коротких документах.

### 8. image_share_check (Доля изображений)
- **Описание:** Анализирует отношение площади изображений к общей площади документа.
- **Сценарии:**
  - Доля изображений в пределах допустимого лимита.
  - Чрезмерно высокая доля изображений.

### 9. decimal_places_check (Знаки после запятой)
- **Описание:** Проверяет точность дробных чисел.
- **Сценарии:**
  - Числа с корректной точностью.
  - Числа с избыточным количеством знаков после запятой.
  - Игнорируемые паттерны: IP-адреса, даты, номера версий.
  - Поддержка и точки, и запятой в качестве разделителя.
