# Проверка Python-кода

Настройки находятся в [ruff.toml](ruff.toml). Из корня проекта:

```bash
.venv/bin/ruff format --check .
.venv/bin/ruff check .
```

Эти же проверки выполняются в CI. Для установки: `.venv/bin/python -m pip install ruff`.
Форматируйте и исправляйте только файлы своей задачи. Перед автоисправлением
проверьте diff; не запускайте массовое исправление чужих изменений.

Тесты и настройка окружения — в [README](README.md#разработка-и-проверки).
